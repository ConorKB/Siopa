# Siopa

A modern marketplace landing page inspired by eBay, built for the `ConorKB/Siopa` repository.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a tiny local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` – page structure
- `styles.css` – marketplace styling and responsive layout
- `app.js` – product data, filtering, search, and sorting logic

## Features

- eBay-inspired marketplace design
- Search and category filtering
- Sort by price or rating
- Hero banner and promotional product card
- Responsive layout for mobile and desktop
- Clean product listing grid with pricing and seller details
